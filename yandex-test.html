Дополнительная проверка: откройте временную ссылку скачивания в новой вкладке Safari. Если JSON откроется или начнёт скачиваться, значит сама ссылка работает, а проблема, вероятно, в программном чтении через JavaScript (CORS).

В ссылке есть временные параметры доступа к тестовому файлу. Не копируйте адрес открывшейся страницы и не присылайте его скриншот. Ссылка может перестать работать через некоторое время.

Что означает результат

Успешный тест подтверждает доступ к папке приложения текущего Яндекс-аккаунта. Обмен между сотрудниками и папками ПХ он пока не подтверждает.

Покажем этап и HTTP-код либо сообщение браузера о сетевом сбое. Если ссылка открывается в Safari, но чтение через JavaScript блокируется, это указывает на ограничения браузерного доступа (обычно CORS). Сам по себе сетевой сбой CORS не доказывает. OAuth-токен и секреты никогда не показываются в сообщениях.
