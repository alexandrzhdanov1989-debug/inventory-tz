Чтение JSON без скачивания файла

Изолированная проверка. Создаётся только один новый тестовый файл в app:/. Данные техники не затрагиваются.

Сессия Яндекса

Проверка…

Если вы не авторизованы, откройте старую страницу теста, выполните вход и вернитесь сюда в той же вкладке.

Два способа чтения

А. Кодируем небольшой тестовый JSON в имени файла, загружаем его, затем получаем имя через API метаданных.

Б. Пробуем записать тот же JSON в custom_properties файла и прочитать через API без скачивания.

Тест ещё не запускался.

Не присылайте OAuth-токен, временные URL, полные адреса ссылок. Отчёт не содержит этих данных.

Важно

Этот тест проверяет только передачу коротких данных в личной папке приложения. Даже успешный результат пока не доказывает доступ к общим папкам сотрудников и пригодность способа для большой базы.
