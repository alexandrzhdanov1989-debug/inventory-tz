РЕЕСТР ТЗ — ЧИСТАЯ ВЕРСИЯ PWA
=================================
В архиве только файлы инвентаризации. Нет тестов Яндекс OAuth, Диска и метаданных.

УСТАНОВКА НА GITHUB PAGES
1. Перед заменой файлов сделайте резервную копию данных в установленном PWA:
   раздел «Резерв» → экспорт JSON. Сохраните JSON отдельно от телефона.
2. В репозитории inventory-tz замените/загрузите 6 файлов из этого архива:
   index.html, app.js, style.css, manifest.webmanifest, icon.svg, sw.js.
3. УДАЛИТЕ ИЗ РЕПОЗИТОРИЯ старые диагностические файлы (если присутствуют):
   yandex-test.html, yandex-test.js,
   yandex-meta-test.html, yandex-meta-test.js,
   yandex-share-test.html, yandex-share-test.js.
   Замена файлов их НЕ удаляет автоматически.
4. Дождитесь публикации GitHub Pages, закройте/откройте PWA заново.
5. Убедитесь, что карточки и изменения на месте; проверьте работу без интернета.

ДАННЫЕ
- Исходная база и изменения остаются в IndexedDB текущего устройства/браузера.
- ZIP не включает реальные данные техники и НЕ импортирует их повторно.
- Не удаляйте PWA, не очищайте данные сайта и не переустанавливайте его до проверки
  резервной копии: на iPhone данные установленного приложения могут быть изолированы
  от Safari, и восстановить их после удаления будет сложно или невозможно.
- Если база отсутствовала, её потребуется импортировать отдельно из локального JSON.
- Автоматическая синхронизация между сотрудниками пока НЕ реализована.
- Учёт сотрудников и PIN-коды добавим позднее, когда будет утверждён их список.
- Тестовые файлы в личном Яндекс Диске это обновление не удаляет.
