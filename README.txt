ИНВЕНТАРИЗАЦИЯ ТЕХНИКИ И ОБОРУДОВАНИЯ
Прототип v1 · 10.11.2026

СОСТАВ ПОСТАВКИ
1) Инвентаризация_ТЗ_WEB.zip — только мобильное веб-приложение (без реальных данных).
2) База_для_импорта.json — исходные 611 записей основного листа Excel.

ВАЖНО: мобильное приложение предназначено для работы в браузере как установленная PWA.
Просто открыть index.html из приложения «Файлы» на iPhone недостаточно для надёжного офлайна.

УСТАНОВКА НА IPHONE
1. Разместите файлы из WEB.zip на HTTPS-хостинге, поддерживающем статические сайты.
   Публикуются ТОЛЬКО index.html, app.js, style.css, manifest.webmanifest, icon.svg, sw.js.
   Не публикуйте База_для_импорта.json: это данные о вашей технике и серийных номерах.
2. Откройте адрес сайта в Safari на iPhone.
3. Меню «Поделиться» -> «На экран Домой».
4. Запустите приложение с домашнего экрана.
5. Перенесите База_для_импорта.json в приложение «Файлы» на iPhone
   (AirDrop, USB, защищённая почта и т. п.).
6. На первом экране приложения выберите этот файл; 611 записей загружаются локально.
7. Закройте приложение и откройте заново. Отключите сеть (авиарежим)
   и проверьте поиск, открытие карточки и сохранение.

КАК РАБОТАТЬ
- «Техника»: поиск по модели, госномеру, RFID, серийному номеру, ПХ и другим данным.
- Откройте карточку, где уже показано оборудование из исходного Excel.
- «Выбрать»: поиск серийного номера среди всех исходных и добавленных устройств.
  Вместе с номером подставляется модель и доступные сведения устройства.
- «✕»: очистить поля данного вида оборудования, без дополнительных статусов.
- «Новый номер»: ввести номер и модель, если нужного устройства нет в базе.
- Активации и подписки доступны для ручного уточнения.
- «Завершить проверку»: сохраняет самостоятельный статус проверки.
- Можно открыть проверенную карточку позднее и исправить данные.
- «Склад»: новые отдельные записи для комплекта или одиночного устройства.
- «Добавить»: новая техника или складская запись.
- «Резерв»: скачивание JSON и CSV для Excel, восстановление JSON.

ЗАЩИТА ОТ ПОТЕРИ ДАННЫХ
- Все изменения записываются в IndexedDB браузера на устройстве.
- Основной исходный Excel при этом не меняется.
- Не удаляйте приложение и не очищайте данные Safari до окончания инвентаризации.
- Регулярно (желательно после каждой смены) скачивайте JSON-резервную копию,
  проверяйте, что она появилась в «Файлах», и переносите копию вне телефона.
- CSV позволяет открыть полный актуализированный набор данных в Excel.
- JSON содержит исходные строки, изменённые записи и отметки проверки.
- Проверка корректности экспорта/восстановления на iPhone обязательна до полевой работы.

ОГРАНИЧЕНИЯ ПЕРВОГО ПРОТОТИПА
- Не тестировался непосредственно на iPhone 15 Pro Max; требуется полевой пилот.
- Нет обмена изменениями между телефонами и автоматического объединения выгрузок.
- Не выполняется анализ конфликтов или перемещений оборудования.
- CSV — не XLSX; открывается Excel, исходные сводные листы не переписываются.
- При выборе серийного номера подтягиваются сведения из первой найденной записи
  этого номера. При расхождениях существующих описаний их можно поправить вручную.
- Публикация HTTPS-оболочки и импорт базы выполняются пользователем вручную.
- Офлайн-доступ зависит от успешной установки и кэширования PWA.
